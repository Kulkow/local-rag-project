# ADR 0009: Автоматическая подготовка PDF из формы загрузки

Форма Documents после успешного сохранения оригинала вызывает существующий
авторизованный сценарий ExtractDocument для MIME из extraction-formats. Сейчас
доступен только PDF. DOCX/HTML сохраняются с явным сообщением об отсутствии обработки.

DDD-границы сохранены: проверка файла и сущности находятся в domain, сценарии
UploadDocument и ExtractDocument — в application, MinIO/PostgreSQL/parser — в
infrastructure. Vue только связывает два существующих HTTP-сценария. Новых
зависимостей, миграций и компонентов инфраструктуры нет.

Успех загрузки и ошибка извлечения отображаются раздельно. Файл и ключ загрузки
сбрасываются сразу после сохранения оригинала. Повтор извлечения доступен из списка,
без повторной загрузки. Ошибка обновления списка не препятствует запуску извлечения.

Это подготовка текста, а не полная RAG ingestion: durable dispatch, чанкинг,
эмбеддинги и индекс отсутствуют. Закрытие страницы между запросами может прервать
автоматический запуск; документ можно обработать вручную. Индексированный статус
не выставляется.

TDD: два новых component-теста сначала упали из-за отсутствующего вызова extractDocument,
после реализации прошли. Дополнительно проверяется сохранение неподдерживаемого
формата без попытки извлечения. Используются synthetic fixtures и моки API, без LLM.
