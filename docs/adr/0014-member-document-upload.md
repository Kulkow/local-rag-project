# ADR 0014: Загрузка документов всеми авторизованными пользователями

По прямому требованию пользователя загрузка разрешена для admin, manager и member.
Анонимный доступ не добавляется. Любой вошедший пользователь может загрузить файл
в доступную ему семью; owner_id всегда берётся из проверенного Principal.

Upload endpoint до чтения body и UploadDocument проверяют доступ к семье без
требования управления ею. Это отдельное право добавления документов, а не расширение
прав member на пользователей/семьи. Ограничения MIME/размера/идемпотентности сохранены.

ExtractDocument, IndexDocument и ManageProcessing допускают владельца документа
при обычном доступе к семье. Для обработки чужого документа требуется прежнее
разрешение управления семьёй и видимость документа. Чужой private остаётся недоступен
для member/manager; admin сохраняет прежние глобальные полномочия. Worker перечитывает
актуального пользователя и проверяет доступ, поэтому загрузка member не останавливается
на последующем extraction/indexing шаге из-за одной лишь роли.

Web Admin показывает форму всем вошедшим пользователям; до выбора семьи поля
отключены. Переиндексация видна владельцу либо admin/manager. Создание семьи остаётся
доступным только admin, пользователь без доступной семьи обращается к администратору.

Новых зависимостей, миграций и изменений JWT/ролей в БД нет. API-формы сохранены.
Регрессионные тесты: member upload (201), owner_id, очередь/process/reindex,
допуск владельца к parser, приватность и cross-family denial; unit tests покрывают
членскую роль на upload/extract/index, frontend — доступность и отправку формы.
