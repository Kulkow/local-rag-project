# ADR 0018: Заголовок документа из извлечённого текста

В Document и documents добавлен nullable title VARCHAR(255), миграция 0011.
Значение появляется после успешного извлечения, а не из имени файла или PDF metadata.
Детерминированная политика ExtractedContent.title: первая строка с буквами из
нормализованных страниц по порядку, пробелы схлопываются, результат обрезается
до 255 символов. Числовые номера страниц и пустые строки пропускаются. Если букв
нет, результат null. Это эвристика, а не гарантированное распознавание заголовка
на обложке; дополнительная модель не вызывается.

Новая extraction сохраняет title атомарно с успешным состоянием в PostgreSQL,
с проверкой generation. Устаревший worker не может изменить title после потери
попытки. Старые документы не удаляются и не переиндексируются миграцией: title null.
ReadExtractedPages после проверки provenance/метаданных артефакта заполняет отсутствующий
title с повторной проверкой generation. Кэшированный ExtractDocument также использует
этот путь. Поэтому чтение текста или переиндексация заполняет title существующего
документа без повторного разбора оригинала. Прежние ACL и проверки семьи сохранены.

DocumentView возвращает title; до extraction, при её ошибке или для форматов без
extractor это null. Documents показывает title с исходным filename ниже; при null
отображается filename. Недоверенный текст заголовка выводится через Vue interpolation,
без HTML. Имя скачиваемого оригинала не меняется. Новых зависимостей нет.

Проверки охватывают кириллицу, пробелы, числовые строки, переход между страницами,
ограничение длины, отсутствие подходящей строки, недоверенный HTML-текст, а также
API/PostgreSQL/MinIO extraction и backfill title с прежней generation.

Результат проверок: Ruff lint/format и strict mypy — passed; pytest с реальными
PostgreSQL/MinIO — 141 passed, 2 skipped. Frontend — 55 passed, TypeScript и Vite
build — passed. OpenAPI/TypeScript-схема обновлены. Миграция 0011 применена;
API/worker/Web Admin обновлены и healthy.
Live smoke SMOKE_MEMBER=1 — passed: worker сохранил title для двух извлечённых PDF,
ошибка парсинга третьего оставила title null. Полный путь RAG/цитат/скачивания и
мониторинг также прошли; синтетические строки и объекты очищены.
