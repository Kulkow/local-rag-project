# ADR 0029: Описание документов и серия мобильных снимков

## Решение

Необязательное `description` хранится отдельно от автоматически полученного title
и текста OCR. Nullable-колонка добавляется миграцией 0014. До 2000 символов,
пробелы по краям удаляются, пустое описание превращается в null, NUL запрещён.
Описание возвращается в DocumentView с теми же проверками семейной области и
видимости, что остальные метаданные. Оно не передаётся модели и не индексируется.

Существующее бинарное тело POST /documents сохраняется. Клиент передаёт описание
в заголовке X-Document-Description через encodeURIComponent, чтобы комментарий
не попадал в URL/access log. Ограничение заголовка — 24000 символов; Nginx принимает
один заголовок до 32 kB. Системы телеметрии не должны записывать этот заголовок.
Описание участвует в проверке идемпотентности. Клиент фиксирует его после первой
попытки отправки, включая неизвестный результат при сетевой ошибке.

Мобильная форма хранит до 20 снимков с отдельными описаниями и отправляет их
последовательно. Каждый снимок остаётся самостоятельным документом с собственным
ключом повтора. После подтверждённой постановки в очередь элемент удаляется из
серии. При частичном сбое успешные элементы не отправляются повторно; для уже
сохранённого оригинала повторяется только планирование. Отмена и размонтирование
очищают временные файлы всей оставшейся серии. Новые зависимости не нужны.

Системная камера Android возвращает в форму после каждого снимка. Постоянное
живое превью камеры с элементами управления приложения не реализовано этим
изменением; для него потребуется отдельная интеграция камеры и проверка жизненного
цикла и разрешений. После отправки форма загрузки остаётся открытой.

## Проверка

Jest покрывает отдельные описания, несколько снимков, продолжение съёмки после
отправки, частичный сбой и безопасные повторы. Python-тесты проверяют нормализацию,
лимиты, хранение описания и конфликт изменения описания с тем же ключом.
Интеграционный тест использует PostgreSQL и синтетическое объектное хранилище.
Физическая камера и сборка нового APK в эти проверки не входят.
