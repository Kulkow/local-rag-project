# ADR 0030: Подготовка снимков для русскоязычного OCR

## Причина

В runtime уже установлены rus/eng, команда OCR использует rus+eng. Однако отдельные
изображения передавались непосредственно в Tesseract без обработки EXIF, контраста
и масштаба. Прежние реальные OCR-тесты использовали английский синтетический текст
и не подтверждали распознавание кириллицы.

## Решение

Добавлен Pillow 12.3.0 (зафиксирован в uv.lock) для декодирования и подготовки
изображений. Декодирование выполняется только внутри существующего изолированного
процесса с прежними лимитами памяти, CPU, файла и wall timeout, никогда в HTTP.
Новых сервисов и внешних OCR API нет.

Последовательность: проверка размеров до декодирования → EXIF-поворот → ограничение
длинной стороны 3200 px → прозрачность на белом фоне → grayscale → увеличение
небольших изображений максимум вдвое в пределах 3200 px → autocontrast → инверсия
преимущественно тёмного фона → белая рамка 20 px. Оригинал не изменяется.
Tesseract сохраняет rus+eng/PSM 3; для отдельных фото добавлены DPI 300 и локальная
бинаризация Sauvola (thresholding_method=2). Обработка PDF не меняется.

Имя нового extractor: tesseract-rus+eng/image-v2. Пустое распознавание по-прежнему
даёт no_text. Ошибки декодирования дают безопасный ocr_failed, временные файлы
удаляются родителем, включая тайм-аут/отмену. Текст не логируется.

Рекомендации: [Tesseract ImproveQuality](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html)
и [Pillow ImageOps](https://pillow.readthedocs.io/en/stable/reference/ImageOps.html).

## Проверки и ограничения

Реальный Tesseract проверяется на синтетических PNG/JPEG с печатным русским текстом,
числами и английским фрагментом: обычное изображение, малый контраст, тёмный фон,
поворот пикселей с EXIF. Отдельно проверяются прозрачность, масштаб и безопасная
ошибка повреждённого файла. Это функциональные регрессии, а не benchmark на фото
пользователя. Рукопись, размытие, перспектива и поворот без EXIF не исправляются
гарантированно; агрессивное повышение контраста может ухудшить некоторые снимки.

Уже сохранённые успешные расшифровки автоматически не изменяются. Существующая
переиндексация использует готовый артефакт, поэтому не запускает новый OCR.
Не выполняется массовое изменение пользовательских документов. Новый снимок
обрабатывается новым extractor; отдельное принудительное перераспознавание требует
следующего среза с явным управлением поколениями расшифровки и индекса.
